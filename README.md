# SQL Practice - MySQL

Hands-on MySQL tasks covering database design, constraints, data insertion and multi-table joins.

![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)

## Databases Built

| Database | Tables / focus |
|---|---|
| `CollegeDB` | Students with courses and marks |
| `LibraryDB` | Books, Members and Borrowing linked by foreign keys |
| `HospitalDB` | Patients with auto-increment IDs |
| `CollegeManagement` | Students with NOT NULL, UNIQUE and UNSIGNED constraints |

## Concepts Practised

- `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`
- Primary keys, foreign keys, `AUTO_INCREMENT`, `NOT NULL`, `UNIQUE`, `UNSIGNED`
- `INSERT`, `SELECT`, `ORDER BY`
- Aggregation with `COUNT` and `GROUP BY`
- `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` and `UNION`
